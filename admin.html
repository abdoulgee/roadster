Connect the pit wall

Live stats are stored in Vercel Blob and written through two Vercel Functions.

  1. In your Vercel project open Storage → Blob and create a store. Connecting it adds BLOB_READ_WRITE_TOKEN.
  2. Set ADMIN_PASSWORD in Project Settings → Environment Variables. Without it the API falls back to qwertyuiop.
  3. Deploy, or run vercel dev locally. Plain npm run dev serves the game but not /api.
  4. Using a private store? Add BLOB_ACCESS=private too (the default is public).
